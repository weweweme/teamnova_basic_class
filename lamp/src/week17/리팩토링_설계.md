# week17 — Laravel 이관 설계

현재 프로젝트(PHP 직접 작성, 파일 80개 · 9,717줄)를 Laravel 13으로 전부 옮기기 위한 설계다.
Laravel 13.31.0 설치와 기존 MariaDB 연결까지는 끝난 상태에서 작성했다.

## 1. 원칙

- **DB는 손대지 않는다.** 기존 표 15개를 그대로 쓰고 Laravel 마이그레이션은 돌리지 않는다.
- **버릴 것과 옮길 것을 먼저 가른다.** 우리가 짠 코드 상당수는 Laravel 방식으로 다시 쓰는 게 아니라,
  **대응 기능이 이미 있어 삭제된다.**
  - *옮긴다* = 우리 로직을 Laravel 방식으로 다시 쓴다 (로직이 남는다)
  - *버린다* = 파일을 지운다. 대응하는 우리 코드가 0줄이 된다
- **단계마다 브라우저에서 확인 가능한 상태로 끝낸다.** 한 번에 전부 바꾸지 않는다.
- **레거시 파일은 해당 기능이 옮겨질 때 지운다.** 그전까지는 남겨 두고 참고한다.

> ⚠ 버릴 때 동작이 완전히 같지는 않다. 예: 지금 `require_csrf()` 는 실패 시 우리가 정한 화면으로
> 보내지만 Laravel은 419 응답을 낸다. 그래서 단계마다 실제 화면 확인이 필요하다.

## 2. 확인된 호환성 (2026-09 측정)

| 항목 | 결과 | 영향 |
|---|---|---|
| 비밀번호 해시 | `$2y$12$` = bcrypt cost 12 | Laravel 기본 해시와 **그대로 호환**. 회원 25명이 비밀번호 변경 없이 로그인된다 |
| `sessions` 표 | `id_hash · last_active · device_id · expires_at` | Laravel 기본(`id · last_activity`)과 다름 → **커스텀 세션 드라이버 필요** |
| `likes` / `votes` | id 없는 복합키 | 모델보다 **관계(belongsToMany) + 피벗**으로 다룬다 |
| 수정 시각 컬럼 | `posts`·`comments` 는 `edited_at` | 모델에 `const UPDATED_AT = 'edited_at'` |
| 회원 시각 컬럼 | `users` 는 `joined_at` 하나 | `$timestamps = false` 또는 `CREATED_AT = 'joined_at'` |
| PHP 확장 | cURL·intl 없음 | Laravel 설치·구동에는 지장 없음. `intl` 은 일부 표시 기능(`Number::format`)에서만 필요 |

## 5. 모델 설계

- `User`(users) — `$timestamps = false`, `CREATED_AT = 'joined_at'`
- `Post`(posts) — `SoftDeletes`, `const UPDATED_AT = 'edited_at'`
- `Comment`(comments) — `SoftDeletes`, `const UPDATED_AT = 'edited_at'`, 자기참조 `parent` / `replies`
- `Media`(media) — `$table = 'media'`, `$timestamps = false`
- `Notification` · `Report` · `Draft` · `Device` · `ConsentLog` · `LoginAttempt` · `PostViewDaily`

관계

- `Post belongsTo User·Media` / `Post hasMany Comment`
- `User belongsToMany Post` (likes) / `User belongsToMany Media` (votes, `choice` 피벗)

## 6. 단계

1. **읽기 전용 뼈대** *(이번 주차 과제의 핵심)*
   - 레이아웃 Blade, 모델 4개, 글 목록 `paginate(15)`, 글 보기 + 댓글 `paginate(20)`
   - CSS·JS를 `public/` 로 복사 — **Vite를 쓰지 않으므로 Node.js 불필요**
2. **인증** — 로그인·로그아웃·회원가입, 요청 제한, 세션(우선 파일 드라이버)
3. **쓰기** — 글·댓글 CRUD, 소프트삭제·휴지통·복구·영구삭제
4. **상호작용** — 추천·감상 투표·신고·알림·조회수 집계
5. **작품·검색·랭킹** — TMDB 연동, 통합검색 3종, 랭킹
6. **계정 고급** — 자동로그인·기기 등록/해제·재인증·다중 기기 로그아웃·유휴 로그아웃, 커스텀 세션 드라이버 이식
7. **부가** — 쿠키 동의, 선호 설정, 초안 저장, 아바타 업로드, 봇 판별
8. **정리** — 레거시 파일 삭제, README·CLAUDE.md 갱신, 남은 줄 수 재측정

## 7. 결정이 필요한 것

- **로그인 식별자** — `users` 에 email이 없다. Laravel 기본 인증은 email 기준이라 **username 기반으로 바꿔 설정**해야 한다.
- **이관 중 레거시 확인 방법** — 문서 루트가 `public/` 이라 지금 옛 화면을 볼 수 없다.
  비교가 필요하면 `public/legacy` 심볼릭 링크를 두는 방법이 있다.
- **TMDB 호출 방식** — Laravel HTTP 클라이언트는 Guzzle을 쓰는데 우리 환경에 cURL이 없다.
  **stream 방식으로 도는지 1단계에서 먼저 확인**하고, 안 되면 기존 `tmdb.php` 호출부를 그대로 둔다.
