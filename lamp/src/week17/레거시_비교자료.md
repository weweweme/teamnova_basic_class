# 레거시 ↔ Laravel 비교 자료

레거시 코드를 지우기 전에 측정해 둔 값. 발표 자료(레거시 vs 리팩토링)의 근거다.
측정 시점: 2026-09-12 · 기능은 양쪽이 같은 상태에서 잰 값이다.

## 1. 규모

| 구분 | 파일 | 줄 |
|---|---|---|
| 레거시 — 화면·처리 | 45개 | 3512줄 |
| 레거시 — includes 모듈 | 31개 | 5744줄 |
| 레거시 — 루트 화면 | 3개 | 455줄 |
| **레거시 합계** | **79개** | **9711줄** |
| | | |
| Laravel — app/ (모델·컨트롤러·서비스·미들웨어) | 43개 | 2933줄 |
| Laravel — resources/views (화면) | 23개 | 1055줄 |
| Laravel — routes/ | 2개 | 150줄 |
| **Laravel 합계** | **68개** | **4138줄** |

> ※ Laravel 쪽에는 `config/`(1,340줄)와 `vendor/`(라이브러리)는 넣지 않았다.
>   설정 기본값과 남의 코드는 '우리가 짠 양'이 아니기 때문이다.

## 2. 손으로 반복하던 것이 얼마나 사라졌나

| 항목 | 레거시 | Laravel | 무엇이 대신하나 |
|---|---|---|---|
| `e()` 직접 호출 | 243곳 | 2곳 | Blade `{{ }}` 자동 escape |
| `require_once` | 207곳 | 0곳 | Composer 오토로드 |
| `require_login()` | 27곳 | 0곳 | `auth` 미들웨어 |
| `require_csrf()` | 25곳 | 0곳 | CSRF 미들웨어 기본 포함 |
| `WHERE deleted_at IS NULL` | 20곳 | 0곳 | `SoftDeletes` 글로벌 스코프 |
| SQL 문자열 실행 지점 | 98곳 | 19곳 | Eloquent·쿼리 빌더 |
| `<form` | 31개 | 25개 | 개수는 비슷하다 — 바뀐 건 **검사 방식**이다 |

> `<form` 개수는 줄지 않는다. 폼은 여전히 폼이다.
> 바뀐 것은 **그 안에서 하던 일**이다 — 조건 확인·오류 문구 작성·폼 되돌리기를
> 순서대로 직접 쓰던 것이, 항목마다 조건만 지정하는 형태가 됐다.

## 4. includes 모듈은 어디로 갔나

**사라진 것 — 프레임워크에 이미 있어서 옮기지 않았다**

| 모듈 | 줄 | 무엇이 대신하나 |
|---|---|---|
| `csrf.php` | 92 | CSRF 미들웨어 · `@csrf` |

| `header.php` + `footer.php` | 296 | Blade 레이아웃 |

## 5. 아직 안 옮긴 것

- `assets/js/main.js` (820줄) — 카운트다운 · 임시저장 자동 호출 · 신고 창 · 가로 스크롤
- `api/browse.php` · `api/row.php` — 스크롤 지연 로딩 (위 JS와 짝)
- `cookies.php` — 쿠키 설명 화면
- `/posts` 의 작품 필터 · 검색어 (정렬 · 감상 필터 · 페이징까지만 옮김)
